# perfect_pop

## Motivation 

Have you ever burnt popcorn? Or stopped the microwave too early and had a bunch of unpopped corns?

Well, I have. 

Once I was preparing some popcorn for a movie night with my wife. And while I was waiting I started counting the pops, also noticed the change in the density of pops over time. 

// plot of a Bell curve 

Suddenly an idea came into my mind: 
``` What if this charactersitic is always the same? ```

You can change the microwave, the power, the brand of the popcorn, but the shape of this curve remains.
